# 🧘‍♂️ ZenSpace - Meditazione Semplice

Benvenuti su ZenSpace, un'applicazione web minimale progettata per aiutarti a trovare calma e concentrazione con citazioni ispiratrici e un timer di meditazione immersivo.

## ## Caratteristiche Principali

*   ✨ **Citazione del Giorno:** Recupera una citazione ispiratrice all'avvio.
*   ⏱️ **Timer Personalizzabile:** Scegli tra 3, 5 o 10 minuti di meditazione.
*   🔊 **Suoni Ambientali:** Includi suoni di Pioggia, Onde, Natura con controllo del volume.
*   💾 **Storico Sessioni:** Salva automaticamente le sessioni completate sul tuo browser.
